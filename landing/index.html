Under the Hood

How Gitler Runs AI On Your Mac

Gitler utilizes a hybrid local inference engine. When packaged as a macOS application, it combines embedded on-device execution with automatic host daemon discovery:

1

Embedded Code Model

Lightweight Qwen2.5-Coder quantized GGUF model executed via Metal acceleration inside the app bundle.

→
2

Ollama & MLX Discovery

Auto-detects high-parameter models on your machine (e.g. Qwen 8B, Gemma 4) with zero manual configuration.

→
3

Diff Tokenizer & Guardrails

Intelligently trims and sanitizes diffs, enforces Conventional Commit standards, and commits directly via native Git.
