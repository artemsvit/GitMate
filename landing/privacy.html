Privacy Policy

Last Updated: October 12, 2026
Executive Summary Gitler is designed from the ground up to respect your privacy. Gitler is a 100% offline-first application. We do not collect, store, sell, or transmit your personal data, source code, repositories, or AI prompts.

1. Zero Telemetry & Tracking

Gitler contains no analytics trackers, diagnostic reporting tools, session replay scripts, or advertising identifiers. When you run Gitler, the application does not report your activity, usage statistics, or crash details to our servers or any third-party analytics services.

2. Source Code and Repository Data

All interactions with your Git repositories remain strictly local to your macOS machine. When you scan folders, view diffs, stage files, or commit changes:

  • Your file contents and commit history are read directly from your local filesystem.
  • No code, file paths, branch names, or author identities are ever transmitted to any external server.
  • File operations execute using standard local Git binaries and POSIX filesystem system calls.

3. Local On-Device AI Models

Gitler provides local AI commit message suggestions powered by Apple Silicon hardware acceleration and local daemons (such as Ollama or MLX):

  • AI inference runs entirely on your local machine using your CPU or Apple Neural Engine / Metal GPU.
  • Your Git diffs and generated commit text are processed in memory on your computer.
  • No prompts, tokens, or commit messages are uploaded to cloud AI providers.

4. Network Communications & Git Providers

Gitler initiates network communication only when explicitly requested by you for normal Git operations or account synchronization:

  • Git Operations: Push, pull, and fetch operations connect exclusively to the Git remotes configured in your repositories (e.g., GitHub, GitLab, or private servers) over SSH or HTTPS.
  • Provider Integrations: When you connect a GitHub, GitLab, or Gitea/Forgejo account, authentication tokens are stored locally on your device with restricted permissions (0600). Gitler communicates directly with your designated server endpoint.
  • Local Network Privacy: In compliance with macOS Sequoia Local Network Privacy (kTCCServiceLocalNetwork), Gitler requests explicit user consent before connecting to self-hosted instances on RFC 1918 private IPv4 addresses (such as 192.168.x.x or 10.x.x.x).

5. SSH Key Security

When Gitler generates a dedicated SSH key pair (~/.ssh/gitler_ed25519) for seamless authentication, the private key never leaves your local computer. Only the corresponding public key is uploaded to your authorized Git providers upon your explicit request.

6. Open Source Verification

Gitler is free and open-source software distributed under the MIT License. The complete source code is publicly accessible on GitHub, allowing developers to inspect and verify our security and privacy practices independently.

7. Contact

If you have any questions or feedback regarding this Privacy Policy, please open an issue or contact the maintainer on GitHub at github.com/artemsvit/Gitler.
