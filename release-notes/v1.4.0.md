Gitler is now **Git Mate**. Your accounts, SSH key, downloaded models, chats, and settings move to the new name automatically on first launch.

### New
- **Graph tab.** See every branch, merge, and tag as a colored history. Filter by branch, search commits, and open a commit to see its files and diffs.
- **AI models.** Choose Qwen3.5 4B, Qwen3.5 9B, or Qwen3.6 27B in Settings → AI Models, or use a model you run in LM Studio or Ollama. Download, pause, switch, and delete models there.
- **Better commit messages.** Written by the local model from your staged changes, following Conventional Commits or your repository's own style.
- **Software update window.** Release notes, download progress, Skip This Version, Remind Me Later, and automatic downloads.

### Improved
- Settings use a sidebar layout.
- The AI Copilot title shows the model in use.
- Clearer SSH key setup in the Remote dialog and in Settings.
- Folder and branch menus match the rest of the app.

### Notes
- If you update from Gitler 1.1 or earlier, the app closes after installing. Open Git Mate from Applications.
- Requires macOS 12 or later on Apple Silicon. Copilot Chat requires macOS 14 or later.
