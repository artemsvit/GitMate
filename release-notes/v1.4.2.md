### New
- **Worktrees.** Extra working folders of a repository — including ones created by AI coding agents such as Codex or Claude Code — appear under their repository in the sidebar. Open one to review its changes, or create, lock, and remove worktrees from the branch menu, the Remotes tab, or a right-click.
- **Stash.** Save work in progress (optionally with new files), then apply, pop, or delete stashes from the Changes tab.
- **Discard changes** for one file or all files. A backup stash is kept for edited files.
- **Amend last commit** from the Commit tab.
- **Commit actions in the Graph.** Right-click a commit to check it out, create a branch or tag, cherry-pick, revert, merge or delete its branch, or copy its hash.
- **Merge and delete branches** from the branch menu. Merges, cherry-picks, and reverts that stop on conflicts show a banner with Abort.
- **Remote branches** in the branch menu. Choosing one creates a local branch that tracks it.
- **Smaller AI models:** Qwen3.5 0.8B and 2B for Macs with less memory.
- **Keyboard shortcuts:** Settings ⌘, · Open Folder ⌘O · Rescan ⌘R · Find Repository ⌘F · Changes, History, Remotes, Graph ⌘1–⌘4 · AI Copilot ⌥⌘C · Commit ⌘↩ · Commit & Push ⇧⌘↩.
