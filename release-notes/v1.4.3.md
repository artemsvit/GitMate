### Improved
- **Push to several remotes faster.** Commit & Push sends the commit to every selected destination at the same time and verifies it on each one.
- **See where a push goes.** The Push to list shows each destination as up to date, commits to push, commits to pull, or new branch. The Commit tab shows which remotes Commit & Push uses.
- **Push counts are accurate.** The number on Push shows the commits the selected destinations are missing.
- **A remote with two push URLs pushes to both by default**, the same as `git push`.
- **Fetch gets every remote**, so each destination's status stays current.
- **Clear push errors.** When a remote has newer commits, Git Mate tells you to pull from it first. When a server refuses a push (for example, a protected branch), Git Mate shows the server's message.
- **Your commit message draft is saved** for each repository and survives a restart.

### Fixed
- A changed or removed push destination no longer drops out of Commit & Push silently. Git Mate asks you to select the destinations again.
- After a push to several remotes, the branch tracks the preferred remote (for example, origin), not the remote that finished first.
- ⇧⌘↩ no longer makes a commit when there is nowhere to push it.
- The diff view clears after a commit, and an old push report hides after a new commit.
- Commit message generation shows the real reason when it fails.
